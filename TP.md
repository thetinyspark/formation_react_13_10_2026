# TP n°6 

- Créez au sein du composant CatalogFilter les filtres supplémentaires suivants: 

- Un filtre sur le nom du jeu (par exemple 'Ma' dans un champ de recherche, alors tous les jeux comportant la chaîne de caractère 'Ma' dans leur nom restent à l'écran, les autres sont filtrés)

- Un filtre sur le prix minimum du jeu, tous les jeux en dessous d'un certain prix sont filtrés

- Un filtre sur le prix maximum du jeu, tous les jeux au dessus d'un certain prix sont filtrés

NOTA BENE : 

    Les éléments HTML concernant les filtres sont contenus dans CatalogFilter mais vous pouvez continuer d'utiliser useMemo qui lui se trouve dans App.jsx
